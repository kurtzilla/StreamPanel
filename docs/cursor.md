# Cursor configuration in this repo

The [`.cursor/`](../.cursor/) directory is **only** for Cursor IDE / Agent integration:

- **[`.cursor/rules/`](../.cursor/rules/)** — [Project Rules](https://cursor.com/docs/context/rules) (`.md` / `.mdc` with frontmatter). These steer the AI agent; they are not general product documentation.

**Everything else** (roadmaps, architecture notes, how-tos) belongs under **[`docs/`](README.md)**—for example **[`docs/plans/`](plans/README.md)**.

Root **[`AGENTS.md`](../AGENTS.md)** stays as a short pointer into rules + README for agents.
